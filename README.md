# Python AI Agent

A powerful, extensible AI agent built in Python that can use various tools to help you with calculations, web searches, file operations, task scheduling, email management, and todo lists. The agent supports both OpenAI and Anthropic (Claude) language models.

## Features

- 🤖 **Multi-Provider LLM Support**: Works with both OpenAI GPT and Anthropic Claude
- 🔧 **Extensible Tool System**: Easy to add new tools and capabilities
- 🧮 **Built-in Tools**:
  - Calculator for mathematical operations
  - Web search for finding information online
  - File operations for reading and writing files
  - Task Scheduler for managing scheduled tasks
  - Email Sender for composing and sending emails
  - Todo List Manager for tracking personal tasks
- 💬 **Interactive CLI**: User-friendly command-line interface
- 🔒 **Security**: File operations with path validation and size limits
- 📚 **Conversation Memory**: Maintains context across the conversation
- 🌐 **MCP Server**: Model Context Protocol server for integration with other applications
